# Crosswalk

Source topics and lessons mapped to the closest Schoolido module, one file per
source and language: for example anton-en.md and anton-de.md.

Each row gives the source lesson (catalogue id), the Schoolido module_id, and
a match: exact, partial or none. Grade alignment comes first; a starting
table for Anton is in anton/notes/prior/2026-10-07-anton-curriculum-research.md
(age alignment), to be extended past G4.
