# lessons

The lesson library, one folder per domain, matching competencies/. Each lesson teaches one step and records its age bands, representation, locale facets, likely item types and any Twist module it reuses. Foreign-language lessons name their target language in the id (fl.en..., fl.fr...).

How a lesson is built (parts, activities, items, variants) and how mastery is decided: [../docs/lesson-anatomy.md](../docs/lesson-anatomy.md). Items are hand-authored.
