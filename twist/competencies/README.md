# competencies

The skill library, one folder per domain: math, lit-de (reading and writing German), lit-en (reading and writing English), fl (early foreign language, shared by Englisch and French), world (Sachunterricht: society, body, nature, space, technology, time). One file per learning progression; each holds its skills in teaching order, with "Ich kann" and "I can" statements, a topic, prerequisites and the standards they serve.
