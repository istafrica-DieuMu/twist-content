# frameworks

One file per official document: its objectives, coded, quoted verbatim, with page references, each mapped to competency steps. de/ holds the KMK standards; gb/ will hold EYFS and the National Curriculum in England. Each file is generated by an extractor in the source folder (official-de/tools/) from the captured document. Land Lehrpläne are kept as reference in official-de/frameworks/, not here.
