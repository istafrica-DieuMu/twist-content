# Schoolido Twist content

The Twist primary curriculum (content) and the research behind it, in one
git repo kept separate from schoolido-learning.

## Layout

- **twist/**: the content. Curricula (de-DE, en-GB) on one shared skill
  library, the lessons, the asset bank, docs and generated views.
  twist/AGENTS.md adds its own rules; twist/PLAN.md holds the steps.
  - Lessons live where the curriculum file places them:
    `twist/lessons/<curriculum>/<year>/<subject>/<skill>.yaml`. The build
    refuses a file in any other folder.
  - views/ is generated by `node twist/build.mjs`: course-de-DE.md (the
    course as authored), tracking.md (coverage, cost, review passes, open
    points; its Reviews section comes from twist/reviews.yaml, so add a pass
    there after each review), coverage and the library.
  - **pages/**: pages built from the content.
    - site/: how the content works and fits together: the chain, curricula,
      task types, components, quality and R&D. Built from the records by
      `node twist/pages/site/build.mjs`; never edit index.html by hand.
    - player/: the lessons in a phone frame, with pictures, drawn
      components and narration, and the Practice tab
      (twist/docs/practice.md): sessions built by player/practice-rules.mjs
      (tests: `cd twist && npm test`) for a pretend child, with drill banks
      from twist/drills/; its screens are player/practice-ui.js and
      player/practice.css. `node twist/pages/player/build.mjs`; it
      plays audio from twist/assets/narration/<voice>/, which is in git
      (about 3 GB); after a content change, narrate the new lines with
      twist/assets/tools/narration.py and commit the new clips.
    - types/: every task type with a screen; `node twist/pages/types/shots.cjs`
      (needs Playwright) retakes the shots. Keep it in step with
      twist/docs/task-types.md. A copy is published as a claude.ai artifact.
    - rewards/: stars and badges, built from twist/docs/rewards.md by
      `node twist/pages/rewards/build.mjs`; never edit index.html by hand.
    - sources/: where every text, picture and sound on a lesson screen comes
      from (the player's label, the v2 field, the record key or asset file,
      the S3 key), written by hand; a copy is published as a claude.ai
      artifact. Update it when a screen, a record key or an asset path changes.
    - handoff/: the handoff to the backend, mobile app and parent dashboard
      teams (IST-B2C/backend, ist-schoolido, IST-B2C/Parent-dashboard),
      written by hand; a copy is published as a claude.ai artifact. Update it
      when twist/ changes what those teams build.
- **rnd/**: the research: the captured sources (anton/, official-de/,
  official-gb/), the catalogue, crosswalk, research site, readiness review
  and the research write-ups. rnd/AGENTS.md has its rules.
- README.md: the quick reference. Keep the root to these, plus config files.

## Rules for every agent session here

- **Keep everything captured.** Never delete, move out, overwrite or "clean
  up" any captured file under rnd/. If disk space or duplicates become a
  problem, stop and ask.
- **Generated outputs are rebuilt, never hand-edited.**
- **Never write into schoolido-learning.** Reading it for comparison is fine.
